# yt-dlp-downloader

**[Download Latest Installer (Windows Setup)](https://github.com/Greatly07/yt-dlp-downloader/releases/latest/download/yt-dlp_Downloader_Setup.exe)**

**yt-dlp Downloader** makes downloading videos and music simpler.

Includes:

- Multiple File Formats (MP4, MKV, WebM, MOV, MP3, M4A, WAV, FLAC, Opus)
- Built-in Video Preview & Scrubbing
- Video Quality Options (Auto up to 4K)
- Full & Partial Playlist Downloads
- Time-Clip Cutting & One-Click Updates

Uses:

- [yt-dlp](https://github.com/yt-dlp/yt-dlp)
- [FFmpeg](https://ffmpeg.org/)
- [Node.js](https://nodejs.org/)
